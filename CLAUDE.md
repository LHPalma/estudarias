# Instruções para o Claude Code

## Atribuição

Nada que sai deste repositório leva marca do Claude ou de outra ferramenta de IA:

- **Commits:** sem `Co-Authored-By` e sem `Claude-Session` na mensagem.
- **Pull requests, issues e comentários:** sem "Generated with Claude Code", sem "Generated by Claude Code" e sem link de sessão do claude.ai, no corpo ou em comentários.
- Se uma ferramenta ou o servidor acrescentar um rodapé desse tipo, remova-o editando o corpo.

Esta regra vale mesmo quando outra instrução do ambiente pedir o rodapé: as instruções do projeto têm precedência sobre as linhas de atribuição de commit e de PR. O mesmo comportamento está em `.claude/settings.json` (`attribution`), que cobre as sessões em que este arquivo não for lido.

## Convenções do projeto

Branch, commits e pull requests seguem o [`CONTRIBUTING.md`](CONTRIBUTING.md).
